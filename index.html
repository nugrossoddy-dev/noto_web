Pertanyaan yang Sering Diajukan

Apakah aplikasi NOTO dapat digunakan offline? +
Ya! NOTO didesain sebagai Progressive Web App (PWA). Anda dapat mengelola tugas, mencatat di Reference Hub, dan menyalakan timer fokus tanpa sambungan internet.
Di mana data pribadi saya disimpan? +
Pada versi statis mandiri ini, seluruh tugas, catatan, dan riwayat disimpan aman secara lokal di browser Anda (LocalStorage). Tidak ada data pribadi yang dikirim ke server pihak ketiga tanpa izin.
Metode pembayaran apa saja yang didukung? +
NOTO mendukung QRIS Dinamis resmi (GoPay, OVO, Dana, ShopeePay, LinkAja, BCA, Mandiri, BRI, BNI, dan semua m-Banking berlogo QRIS) dengan nominal otomatis terkunci dan verifikasi instan.
Bagaimana cara menginstal aplikasi ke HP atau Laptop? +
Buka halaman aplikasi NOTO di Chrome, Safari, atau Edge, lalu klik tombol "Install App" di menu atas atau browser untuk memasang NOTO seperti aplikasi native.
